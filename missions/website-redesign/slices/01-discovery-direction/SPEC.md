# Slice 01: Research and design direction

## Intent

Find a distinctive visual language for zero and create buildable desktop and mobile mockups before editing landing code.

## Mini-requirements

1. Inspect current live zero, source `landing/`, assets, README, PRODUCT.md, and current DESIGN.md. Use the updated `/impeccable` replacement-world process, including its concept direction assignment and decision step.
2. Compare Linear, Raycast, Vercel and one additional current first-party product site by actual composition, typography, product imagery, navigation and motion, with dated URLs. Distinguish inspiration from copying.
3. Define the visual system and first viewport around zero's actual mechanism. Produce desktop and mobile mockups with a truthful app image and visible install path, plus a handoff design brief. Avoid fake UI or invented proof.
4. Record what must stay: install/installer, privacy, terms, accessibility, app constraints and costs.

## Proof contract

- [ ] Research notes and citations identify observed reference patterns and zero's real claims.
- [ ] A selected direction, rationale, risks, and desktop/mobile mockups are attached for builder comparison.
- [ ] Mission owner acknowledges the direction before build begins.
