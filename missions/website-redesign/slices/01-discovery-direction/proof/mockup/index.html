Keep the mail that needs you.

zero is a Mac menu-bar app. It checks your Gmail, keeps the conversations that still need you, and archives the rest. Archived mail stays in Gmail, and you can restore it.

What stays. What's set aside.

zero reads each conversation against plain-language rules you can edit in Settings. If it still needs your reply or action, it stays in your Inbox. Everything else is archived.

It can be wrong. Review your first few runs.

Install zero.

About four steps from Terminal to your first sweep.

  1. Run the installer in Terminal.

    Read first: zero isn't Apple-notarized, and the installer may add developer tools. Read the script before you run it.

    $ curl -fsSL https://zero.headless.com/install | bash

    Prefer a download? Use GitHub Releases.

  2. Connect Gmail.

    Open zero from the menu bar and choose Connect your first inbox.

  3. Add your Jev key.

    In Settings → Sorting engine, choose Get a key, paste it and save.

  4. Run your first sweep.

    Choose Run zero now. Check what stayed and what was archived, then pick a schedule in Settings.

Questions

Does my email stay on my Mac?

No. zero runs on your Mac, but sends thread text to TypeSafe's Jev for sorting. Reply drafts go to your chosen AI provider. The zero project doesn't run a server that receives your email.

What if it archives something important?

It can happen. The mail stays in All Mail with a dated recovery label, and zero's Undo view restores a run.

Can zero send email for me?

Only when you click Send reply on a draft you've reviewed.

Can I use more than one Gmail account?

Yes. Their conversations appear together in Open loops.
