# Ten-reference atlas

- **Inspected:** 2026-09-29 (UTC) by design-lead@zero.
- **Method:** one Aside session per batch opened each live page at a 1440×900 CSS viewport (2880×1800 device pixels), took a first-viewport and one scrolled screenshot, and read computed `body` background, font stacks and `h1` metrics in the page. Batch A was Aside task `154401a085`. Its JSON was lost to an Aside `ENOENT process.cwd` error, so batch A notes come from the screenshots only. Batch B was Aside task `3516485kda`, and its computed values are quoted below.
- **Evidence:** `refs/<key>-1.jpg` is the first viewport, and `refs/<key>-2.jpg` is scrolled. Both are 1200 px JPEG reductions of the Aside PNGs.
- **Scope:** Vercel and Arc were also inspected and left out. Vercel is a second instance of the dark infrastructure template that Linear already calibrates. Arc's homepage is currently a hand-off page to Dia, so it no longer represents Arc.

The ten span four families: dark product-precision, light product-honest, object and editorial, and quiet utility. Only three of them are dark.

## What the set teaches, taken together

1. **Real product first.** Linear, Things and Tailscale all let working UI carry the proof. zero has one real app image. It should be the largest element on the first screen and never be recoloured or mocked.
2. **One authored world, held totally.** Teenage Engineering and Raycast each commit to a single physical idea. Scattering motion and effects across sections is what made the departure board read as assembled.
3. **Say the absence plainly.** Granola's "Without a meeting bot" and HEY's named "Screener" show that the rule is the product. For zero, the absence is "Nothing is deleted."
4. **Install honesty as design.** Raycast and Tailscale put requirements and the real command in plain view. zero's non-notarized warning and `curl | bash` deserve that same calm, first-class treatment, not an alarm stripe.
5. **Light is meaning or nothing.** Raycast's light sculpture and Mercury's dawn scene both use light, but only Mercury's means something. Direction A uses light only to mark what needs you.
