## 1. Avatar: Sam, the Mac builder

Sam is a solo founder or freelance coder. They use an Apple Silicon Mac on macOS 26, Gmail, Terminal, and Claude Code or Codex. They can set up a key. They want less work, not another tool to tend.

Their day: ship code, take a call, check mail, lose focus. A client reply sits among receipts and cold pitches. Sam checks again because they fear they missed it.

Pain words to test, not real quotes:
- “I already replied. Why is this still in my inbox?”
- “Which of these actually needs me?”
- “I want AI to sort mail. I don't want it to send mail.”

This is not yet for every busy Mac user. Terminal, Google setup, AI keys, and an unsigned app screen out most people. Start with builders who own their inbox and can approve the AI use. Skip locked-down work Macs.

These are targets, not promised coverage. Check each group's live rules before posting. Do not paste the same ad everywhere.

## 3. Value ladder: trust first, ease later

**Bait:** A public 45-second demo. “Watch mail leave the inbox. Now watch it all come back.” Show the source too. No email gate.

**First yes:** Inspect the script, install free, connect Gmail and AI, run one sweep, try undo. One install command does not mean one-step setup.

**Next yes:** Use it for seven mornings. Tune what “needs me” means. Ask for one bug report or a note on one wrong call. Let people opt into release notes. Do not require a list signup to use it.

**Future offer:** “Like the calm? Skip the keys and setup. Hosted zero: $4.99/month.” Mark this as planned, not on sale.

**The hard truth:** Many free users will never pay. They already have the skills and AI access. Do not make free worse to push them up.

This is two paths, not a strong upgrade ladder. Builders help prove the tool and refer friends. Busy non-builders pay for less setup and upkeep. A few builders may pay to stop tending it.

To earn $5, hosted must remove real work: no install, no key, managed runs, and clear usage limits. Those are future requirements, not shipped features. Test demand with a price-marked waitlist. Check AI, hosting, Google approval, and support costs before promising that price works. Explain the new data path before anyone switches.

## 4. Homepage: Hook → Story → Offer

### Five hooks
1. **Your inbox. Only what needs you.**
2. Stop sorting mail. Start with what needs you.
3. Keep the replies. Clear the noise.
4. Let your Mac sort the morning mail.
5. An inbox you can finally ignore.

The old headline survives as a brand line. It sells relief well. It is weaker as the main promise: some mail still needs you. Lead with option 1. Test the old line later.

**Subhead**
“zero reads each Gmail thread each morning. It keeps what still needs you and archives the rest. Nothing is deleted. Undo any run. Free for your Mac.”

**Story**
“You check mail. Then check again. Not because you love email. Because someone might be waiting. zero sorts the noise from the work. You see what needs you, then get back to your day.”

**Offer stack**
- A quiet menu-bar app. Keep using Gmail.
- A morning sweep across your accounts.
- Undo for archived mail. Nothing deleted.
- Drafts in your voice, when you ask. It never sends.
- Free code you can read and change, subject to the license fix below.

**Main button:** “Install free.” Show the one-line command beside “Read the install script.”

**Plain setup note:** “macOS 26. Apple Silicon. Bring a Jev key from TypeSafe AI, or use your installed Claude Code, Codex, or opencode. AI costs may apply. Jev sorts mail. Reply drafts need a text model.”

**Trust note:** “No zero backend. The app runs on your Mac. Your chosen cloud AI may receive mail text. A CLI on your Mac does not mean the AI runs there.”

State that this is not an App Store or notarized app. Explain the install script's quarantine step before people run it.

## 5. The 30-day launch

| Days | Where and what | Next yes |
|---|---|---|
| 1–3 | Resolve license, Google setup, provider, and privacy claims. Record sweep plus undo. | Three builders try a clean install. |
| 4–7 | Invite five known Mac builders. Hook: “Which mail needs you?” Show one sweep. | Run it and name one wrong call. |
| 8–10 | With permission, post the workflow to MPU and r/macapps. | Five more testers. |
| 11–14 | Post the CLI story to one Claude subreddit. Pitch Changelog and Console. | Try the free tool, not a waitlist. |
| 15–18 | Fix setup snags. Publish known limits and one consented user story. | Use it for seven mornings. |
| 19–21 | Publish GitHub release and Show HN: “Show HN: Zero, a Mac app that keeps Gmail at only what needs you.” Explain why, show undo, link install. | Try it and ask hard questions. Be there to answer. |
| 22–25 | Share lessons on DEV and Indie Hackers. Reply to every useful bug report. | Help test fixes. |
| 26–28 | Launch on Product Hunt only if new users can finish setup. Otherwise fix it first. | Install free. |
| 29–30 | Publish what worked and failed. Ask opt-in users about the $4.99 hosted path. | Join a price-marked interest list. |

No fake close date. No vote requests. Track clean installs, first sweeps, successful undo, seven-day use, wrong archives, and hosted interest. Use consented tester reports, not mail telemetry. Stars are not the goal.

### Launch gates and sources

README also describes bring-your-own Google OAuth setup. Verify the real new-user path before a broad launch.
